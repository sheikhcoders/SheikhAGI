# Skill: CI/CD Workflows

Specialized workflows for automated testing, building, and security provenance.

## SYNOPSIS
```bash
/invoke slsa_provenance
/invoke webpack_build
```

## DESCRIPTION
The **CI/CD Workflows** skill provides pre-configured agentic scripts to handle the project's lifecycle, from building Node.js assets to generating SLSA security provenance.

## INTERFACE (Commands)
- `/invoke slsa_provenance`: Generates SLSA3 provenance for release workflows.
- `/invoke webpack_build`: Builds the project using npm and Webpack.
- `/invoke deno_test`: Runs tests for Deno-based modules.

## DETAILS
These workflows are aligned with industry best practices for supply chain security and performance optimization.

## BACKGROUND
Designed to ensure the **Sovereign (S)** and **High-Performance (H)** pillars of the SHEIKH framework through automated reliability.
