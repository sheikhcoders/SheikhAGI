# Logic Synthesis: Integrating Reasoning Paradigms

This document provides a technical deep-dive into how disparate reasoning logics are integrated into the **Amar Sonar AGI** model.

## 1. Internalized Chain-of-Thought (CoT)
The core of the model's reasoning is the `<think>` token block. This is not just a UI element but a fundamental part of the model's output distribution.

### 1.1 Training for CoT
We use **Supervised Fine-Tuning (SFT)** on datasets like:
- **STaR (Self-Taught Reasoner)** traces.
- **OpenMathInstruct-1** for mathematical rigor.
- **Synthetic reasoning traces** generated by larger models (e.g., DeepSeek-V3).

## 2. Test-Time Compute (TTC) Mechanism
TTC allows the model to "think harder" for harder problems.

### 2.1 Dynamic Computation
The model utilizes a **Router** that determines the complexity of the input.
- **Low Complexity**: Direct response.
- **High Complexity**: Invokes a multi-step search through the thought space.

### 2.2 Mathematical Framework
The probability of a correct answer $y$ given input $x$ and compute budget $C$ is modeled as:
$$P(y|x, C) = \sum_{z \in \mathcal{Z}_C} P(y|x, z)P(z|x)$$
where $\mathcal{Z}_C$ is the set of reasoning paths searchable within budget $C$.

## 3. Interleaved Thinking (Plan-Act-Reflect)
The "Interleaved Thinking" logic is achieved by training the model on **agentic trajectories**.

1.  **Planning**: Generating a structured DAG (Directed Acyclic Graph) of sub-problems.
2.  **Acting**: Using specialized tool-calling tokens to interact with a Python interpreter or search engine.
3.  **Reflecting**: A self-correction phase where the model inspects the `stdout` or `stderr` of its actions.

## 4. Synthesis via GRPO
**Group Relative Policy Optimization (GRPO)** is used to align these three logics. By rewarding the model for correct answers and valid reasoning paths, it naturally learns to balance TTC and Interleaved Thinking.

> "The magic happens when the model realizes that 'thinking' is just another form of 'acting' in the latent space."
